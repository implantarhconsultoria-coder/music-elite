# Music Elite

Aplicativo mobile real de formação musical de elite.

Stack: React Native + Expo + TypeScript.

## Fase 1 — Onboarding & Diagnóstico Adaptativo

Telas implementadas:
1. Splash / Welcome
2. Escolha do instrumento
3. Autoavaliação de experiência
4. Diagnóstico adaptativo (ajusta dificuldade, pontua competências, calcula nível, identifica força/deficiência, persiste resultado)
5. Resultado do diagnóstico

Home existe apenas como destino técnico mínimo.

### Como rodar
```bash
npm install
npx expo start
```
