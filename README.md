# Music Elite

Plataforma premium para artistas e ouvintes de elite.

## Fase 1 - Concluída

Estrutura base com landing page responsiva, design escuro premium (preto + ouro), navegação suave e preview estático.

### Arquivos principais
- `index.html` - Página principal
- `css/styles.css` - Estilos completos
- `js/main.js` - Interações básicas
- `README.md` - Esta documentação

### Como visualizar
1. Clone o repositório
2. Abra `index.html` no navegador
   ou
3. Sirva localmente: `python -m http.server 8000` na pasta do projeto e acesse http://localhost:8000
